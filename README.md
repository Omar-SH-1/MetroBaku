
# 🚇 MetroBaku Simulation

Симуляция движения поездов метро по красной и зелёной веткам метро Баку.  
Проект демонстрирует работу многопоточности в C++ с использованием `std::thread`, реалистичной задержки движения и логированием в консоль.

## 🚆 Описание

Программа запускает несколько виртуальных поездов:
- Поезда с чётным ID (0, 2, ...) — зелёная линия (`GreenmetroTrain`)
- Поезда с нечётным ID (1, 3, ...) — красная линия (`RedmetroTrain`)

Каждый поезд:
- Проезжает станции по маршруту в прямом и обратном направлении
- Делает остановки и развороты на конечных
- Показывает текущее время прибытия/отправления
- Печатает лог движения в консоль в режиме реального времени

---

## 🧵 Многопоточность

Каждый поезд запускается в отдельном потоке с помощью `std::thread`, что симулирует их независимое движение.  
Чтобы избежать накладок при выводе сообщений в консоль из разных потоков, используется `std::mutex console_mutex`.

---

## ⚙️ Настройки

Настраиваемые параметры находятся в `metrobaku.cpp`:

- `travel_time` — время в секундах на проезд между станциями
- `stop_time` — время остановки на станции
- `turnaround_time` — время разворота на конечной станции
- `train_start_delay` — задержка запуска между поездами
- `max_round`, `max_round_2` — количество кругов движения для красной и зелёной линии соответственно
